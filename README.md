# 博客精读 · Blog Deep-Read

每期挑一个博客／写作者，把这个头脑**最精华的思想**提炼出来讲透。目标：**读完这一页，约等于把这个人读通了**——他在跟什么问题较劲、给出了哪几个真正原创的答案、他怎么想问题、他哪里可能是错的。

不是博客简介，不是文章列表，不是安利。是**提纯一个头脑**。

→ **<https://cissy0802.github.io/blog-deepread/>**

## 清单怎么来的

`TOPICS.md` 里的 54 个博客，来自**四家旗舰模型的独立选片**：

| 模型 | 厂商 |
|---|---|
| GPT-5.5 (xhigh effort) | OpenAI |
| Gemini 3.1 Pro | Google |
| Claude Opus 5 | Anthropic |
| Claude Fable 5 | Anthropic |

每家各推 20 个：**15 个对准兴趣 + 5 个 surprise**（专门用来打破信息茧房），并有多样性硬约束（地理、性别、学科、活跃/停更、长文/技术各档配比）。四家共 80 条，按域名 + 作者 union-find 去重得 54 个，**全部 URL 实测可达**（剔除了一个域名已失效的）。

排序：跨模型票数为主序，同票内**强制领域交错**（保证连续几期不撞同一领域），`[surprise]` 均匀撒开（平均每 3 期一个）。

## 两条 routine

- **日更**（`CLAUDE.md`）：按 `TOPICS.md` 顺序，每天精读一个博客，产出中英双页 `{slug}-blog{N}.html` / `.en.html`。**必须先真读**——WebFetch 主页 + 实际读 4–6 篇跨时期代表作；读不到就不发布、报告请人核实，绝不靠记忆编。
- **月更**（`REFRESH.md`）：每月回访已发布页面，把它们对齐到作者的**当前**状态。博客和论文不同——作者还活着、还在写、还会推翻自己。只有「深化 / 自我推翻 / 新命题 / 重要争论 / 停更」才值得记；「他又写了一篇好文章」不算更新。

## 约定

- `TOPICS.md` **人工维护，routine 只读不改**（`publish.sh` 硬卡）。清单写完 → 推送请人续单，不自造主题。随时可以往里加博客，外部守卫会自动重开 trigger。
- 发布走 `./publish.sh`（体量、index 引用、div 平衡、重复编号、TOPICS 未改等校验）。
- 共享脚本（comments / search / index-button / i18n-tts / lightbox）由 GitHub Action 自动注入，**别手写**。
